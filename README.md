# Vennela Co-Live

Luxury co-living accommodation in Electronic City, Bangalore.

## 🌟 Highlights
- **Prime Locations**: Electronic City Phase 1, conveniently situated near Infosys and Wipro gates.
- **Modern Living Spaces**: Fully furnished private and sharing rooms with high-speed Wi-Fi, housekeeping, and dedicated workspaces.
- **Top Amenities**: Rooftop gym, homestyle food dining, 24/7 security, power backup, and community lounge.

## 📁 Project Structure
- `index.html` - Vennela Co-Live main portal and overview
- `pg1.html` / `pg1.css` - Branch 1 showcase and details
- `pg2.html` - Branch 2 showcase and details
- `Vennela Co-Live PG.html` - Additional branch view
- `images/` - High-resolution property photography and assets
- `videos/` - Walkthrough videos and virtual tours

## 🚀 Getting Started
Open `index.html` in any modern web browser to preview the website locally.
